# Inline source icons

- `source-github.svg`: Font Awesome Free 6.7.2 GitHub brand icon. SVG attribution retained. Icons licensed under CC BY 4.0: https://fontawesome.com/license/free
  Source: https://cdn.jsdelivr.net/npm/@fortawesome/fontawesome-free@6.7.2/svgs/brands/github.svg
- `source-arxiv.svg`: Simple Icons arXiv mark, CC0. Source: https://github.com/simple-icons/simple-icons/blob/develop/icons/arxiv.svg
- Blog, paper, documentation, and evaluation icons: original line drawings for source types, not publisher logos.

Source links provide their own accessible labels and tooltips; icon images are decorative.
Every inline citation pairs its icon with a visible reference number such as `[1]`,
matching the article's numbered reference list. This also applies to figure captions.
