One kind of objective. Two ways to change a distribution.
The left uses a categorical model; the right uses a Gaussian generator. Each follows its own optimization trajectory.

What is being computed?

Left: 13 outcomes with softmax probabilities. Each step uses the exact expected OPD policy gradient: Δθᵢ = η qᵢ(rᵢ − ∑ⱼqⱼrⱼ), where rᵢ = log(pᵢ/qᵢ). The initial probabilities use a Gaussian centered at −1.2, mixed with 3% uniform probability to represent every outcome. Right: q = N(μ, 0.85²), p = N(1, 0.85²), with x = μ + 0.85z and initial μ = −1.2. Mean updates follow Δμ = η(1 − μ)/0.85². Dots are fixed quantiles translated with the mean; the curve shows the exact density. The categorical target is the normalized target Gaussian density evaluated on the outcome grid.

The MSE gradient is exact. The sampled average is an estimate.
The mean is held fixed throughout. Gradient descent would subtract −1 and move it toward the teacher.

What is being computed?

Here δ = μ − μT = −1 and a = μ + ε, with ε ∼ N(0,1). The sampled log-ratio cost is c(a) = log q(a) − log p(a) = ½ − ε. The fixed-action score ∂μ log q(a) = ε, so g = ½ε − ε² and E[g] = −1. The plot uses 512 seeded independent pseudorandom samples and a logarithmic sample-count axis. More samples reduce the average's variance; an individual run need not approach −1 monotonically.
